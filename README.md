# Istranet — личный кабинет в Home Assistant

Пользовательская интеграция на основе `istranet_balance.py` для AppDaemon.
Настраивается через интерфейс Home Assistant, AppDaemon не требуется.

## Быстрая установка

**1. Добавить репозиторий и скачать интеграцию через HACS**

[![Добавить в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ipmerlin&repository=ha-istranet&category=integration)

**2. Перезапустить Home Assistant, затем добавить Istranet**

[![Добавить интеграцию в Home Assistant](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=istranet)

HACS должен быть уже установлен. При первом переходе My Home Assistant попросит
указать адрес вашего HA. Вторая кнопка работает после скачивания интеграции и перезапуска.

## Возможности

- Баланс, сумма к оплате и статус подключения.
- Тариф, абонентская плата, скорость тарифа и дата списания.
- IP-адрес, маска, шлюз и DNS.
- Обновление каждые 60 минут; интервал от 5 до 1440 минут меняется в настройках.
- Кнопка ручного обновления.
- Сумма пополнения, кнопка «Получить QR СБП» и изображение QR для банковского приложения.
- Несколько логинов, автоматическое обновление токена, повторный ввод пароля через HA.
- Русский и английский интерфейс; приложенный пользователем логотип.

## Установка из ZIP

1. Распакуйте `dist/istranet-0.1.0.zip` в каталог конфигурации HA.
   Должен получиться файл `/config/custom_components/istranet/manifest.json`.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Istranet**.
4. Введите логин и пароль личного кабинета `https://lk.istranet.ru`.
5. На странице устройства добавьте нужные сущности на панель.

Минимальная версия HA: **2025.12**. Для отображения локального логотипа требуется
**2026.3 или новее**: [документация HA](https://developers.home-assistant.io/docs/core/integration/brand_images/).
HA автоматически установит библиотеку `segno==1.6.6` для создания QR.

## HACS

Репозиторий: https://github.com/ipmerlin/ha-istranet

1. В HACS откройте меню → **Пользовательские репозитории**.
2. Добавьте `https://github.com/ipmerlin/ha-istranet`, категория **Интеграция**.
3. Найдите **Istranet**, скачайте и перезапустите Home Assistant.
4. Добавьте интеграцию **Istranet** в настройках HA и введите данные ЛК.

## Пополнение через СБП

На странице устройства доступны:

1. **Сумма пополнения СБП** — целые рубли от 10 до 100000; начальное значение 890 ₽.
2. **Получить QR СБП** — запрашивает платёжную ссылку для выбранной суммы.
3. **QR для оплаты СБП** — изображение, которое можно добавить на панель и сканировать.

Диапазон суммы — ограничение интерфейса интеграции; провайдер может отклонить запрос
по собственным правилам. Изменение суммы само по себе не создаёт запрос.
Окончательные сумму и получателя проверяйте при подтверждении в банковском приложении.
Автоматического списания и подтверждения платежа интеграция не выполняет.

Изображение хранится только в памяти HA. Оно очищается при смене суммы, новом запросе,
перезапуске/перезагрузке интеграции и через 15 минут. Это срок показа в HA,
а срок действия платёжной ссылки определяет банк. После оплаты нажмите «Обновить данные»
или дождитесь очередного обновления баланса; статус оплаты отдельно не отслеживается.

Метод проверен по клиентскому коду действующего ЛК 14.09.2026:
`GET /api/payment` → `types` → тип `qr`; `POST /api/payment` с `type`, `amount`
и `Idempotency-Key` → `url` на `https://qr.nspk.ru/`.
В браузере получен QR для согласованных пользователем 890 ₽.
Скрипт НСПК кодирует адрес страницы в QR; интеграция кодирует полученную ссылку локально,
без передачи логина, пароля или токена на сайт НСПК.

## Датчики и переход с AppDaemon

Сохраняются 12 типов датчиков исходного скрипта. Дублирующий датчик «Стоимость тарифа»
изначально выключен: его можно включить в списке сущностей, основным служит
«Абонентская плата». Сетевые параметры помечены диагностическими.

Идентификаторы сущностей HA создаёт при добавлении. Для переноса существующих карточек
и автоматизаций отключите старое приложение AppDaemon и переименуйте новые сущности
в прежние `sensor.istranet_balance`, `sensor.istranet_tariff` и т. д.
Иначе замените ссылки на датчики в ваших карточках и автоматизациях.
Не используйте одновременно одинаковые идентификаторы старого и нового приложения.

При недоступности тарифа баланс продолжает обновляться. При сбое `/account` все
датчики становятся недоступны до успешного обновления; старое значение не выдаётся за новое.
Пропущенные или некорректные числа не заменяются нулём.
Текущий тариф в списке определяется по `type=current`, затем по единственному
`enabled/active`; произвольное предложение из списка не выбирается.
Если текущих тарифов несколько, датчики тарифа остаются недоступны — объединение
нескольких тарифов в этой версии не поддерживается.
Дата списания трактуется как Unix-время в секундах, календарная дата — по Москве.
Стоимость услуг тарифа учитывает процентные скидки и округление каждой услуги вверх
до рубля, как в текущем веб-кабинете. Другие самостоятельные услуги, пакеты ТВ и камеры
в абонентскую плату тарифа не включаются.

## Данные и диагностика

Логин и пароль сохраняет Home Assistant в своей конфигурации, токен хранится в памяти.
У каждого логина отдельная сессия. Токены, пароли и полные ответы API в журнал не выводятся.
Диагностика содержит только интервал обновления, результат последнего обновления и
названия доступных полей. Она не содержит адресов, баланса или платёжных ссылок.

## Проверка и сборка

```shell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
ruff check .
ruff format --check .
python scripts/write_translations.py
python scripts/build.py
```

Тесты API и разбора данных работают без реального аккаунта, на искусственных ответах.
`tests_ha` проверяет формы, жизненный цикл, сущности и состояние QR с реальными классами
Home Assistant в Linux CI. Тесты API и тесты HA успешно прошли на GitHub Actions.
Статус проверки метаданных hassfest доступен на вкладке Actions репозитория.
Проверка интеграции с реальным сервером HA остаётся шагом после установки.

Сборка ZIP включает только файлы интеграции и логотип, без тестов, временных скриптов
и данных личного кабинета.
