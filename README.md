# Istranet — личный кабинет в Home Assistant

Баланс, тариф и сетевые параметры Istranet в Home Assistant. Пополнение через QR СБП, настройка через интерфейс HA и поддержка нескольких аккаунтов.

## Установка

Требуется **Home Assistant 2025.12+** и установленный HACS. Логотип отображается с HA 2026.3.

**1. Добавьте репозиторий в HACS и скачайте интеграцию.**

[![Добавить в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ipmerlin&repository=ha-istranet&category=integration)

**2. Перезапустите HA, добавьте Istranet и введите логин и пароль [личного кабинета](https://lk.istranet.ru/).**

[![Добавить интеграцию в Home Assistant](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=istranet)

При первом переходе укажите адрес вашего HA. Если добавляете репозиторий вручную: `https://github.com/ipmerlin/ha-istranet`, категория **Интеграция**.

Без HACS: скачайте ZIP из [релиза](https://github.com/ipmerlin/ha-istranet/releases/latest), распакуйте в каталог конфигурации HA, чтобы появился `/config/custom_components/istranet/manifest.json`, затем выполните шаг 2.

## Сенсоры

| Сенсор | Что показывает |
| --- | --- |
| **Номер лицевого счёта** | Номер аккаунта, отображаемый в личном кабинете как ID. |
| **Баланс** | Текущий остаток средств на счёте, ₽. |
| **К оплате** | Сумма к оплате, переданная личным кабинетом, ₽. Не рассчитывает, сколько нужно внести к следующему списанию. |
| **Статус подключения** | Состояние аккаунта у провайдера: активно, заблокировано или отключено. Не проверяет доступность интернета. |
| **Тариф** | Название текущего тарифного плана. |
| **Абонентская плата** | Стоимость услуг текущего тарифа за расчётный период, ₽, с учётом скидок. Отдельные услуги, ТВ-пакеты и камеры не включаются. |
| **Стоимость тарифа** | Дублирует абонентскую плату; по умолчанию выключен. Можно включить в списке сущностей. |
| **Скорость тарифа** | Скорость, указанная в тарифе, Мбит/с. Это не результат замера скорости. |
| **Дата списания** | Дата следующего списания по тарифу, по московскому времени. |
| **IP-адрес** | Первый IPv4-адрес подключения из ЛК. Маска сети доступна в атрибутах сенсора. |
| **Шлюз** | Адрес сетевого шлюза. |
| **DNS 1** | Первый DNS-сервер. |
| **DNS 2** | Второй DNS-сервер. |

Сетевые сенсоры находятся в разделе **Диагностика**. Если данные отсутствуют или не удалось их получить, соответствующие сенсоры становятся недоступны. Поддерживается один текущий тариф на аккаунт.

## Оплата через СБП

Если название тарифа содержит **«Юр»** (без учёта регистра), поле суммы, кнопка оплаты и QR скрываются и отключаются. При смене тарифа правило применяется после обновления данных.

1. В поле **Сумма пополнения СБП** укажите целую сумму от **10 до 100000 ₽**.
2. Нажмите **Получить QR СБП**.
3. Откройте **QR для оплаты СБП**, отсканируйте его банковским приложением и подтвердите платёж.

**QR для оплаты СБП** — сущность изображения: её можно добавить на панель. В списке сущностей отображается время создания QR.

QR запрашивается только по нажатию кнопки. При смене суммы, новом запросе, перезапуске интеграции или через 15 минут изображение очищается. Срок действия самой платёжной ссылки определяет банк.

После оплаты нажмите **Обновить данные**, чтобы проверить баланс. Статус платежа отдельно не отслеживается.

## Обновление данных

По умолчанию данные обновляются **раз в 60 минут**. Интервал можно изменить от **5 до 1440 минут** в настройках интеграции. Кнопка **Обновить данные** в разделе **Диагностика** запускает обновление вручную.

Если пароль ЛК изменился, HA предложит повторно ввести данные входа.
